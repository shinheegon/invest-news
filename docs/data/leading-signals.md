## 🧠 선행신호 패턴 라이브러리
1. **첫 대형 고객사 납품/공급계약 공시(실적 반영 전)** — 계약 체결~실적 인식 사이 수개월 시차 동안 저평가 상태 지속, 과거 실적 반영 시점에 재평가. 예: 자람테크놀로지 유럽 수주.
2. **캐파(증설)·신규라인 발표** — 신규 라인 가동 발표 후 실제 가동률 상승까지 시차 존재, 이 구간이 매수 기회.
3. **성장 테마 밸류체인에 처음 거론(언급 빈도 0→1)** — 단, 구체 재료 동반 시에만 유효(구체재료 없으면 theme-first-only 회피패턴에 해당).
4. **신제품/특허/인증/국산화 성공** — 기술 검증 완료 후 매출 반영까지 시차 존재.
5. **실적 턴어라운드 조짐(수주잔고↑·가동률↑인데 주가 미반영)** — 재무 선행지표가 주가에 반영되지 않은 구간.
6. **수급 전환 초기(기관/외국인 순매수 막 시작)** — 대형 이벤트 이전 스마트머니 선취매 신호.
7. **자본 재배치(자회사 지분 추가취득 등)** — 사업 강화 의지 신호이나 수요측 증거(수주)가 뒤따라야 지속력 확보. 예: 엠엑스온.
